# Orbit 小球视线与提醒任务文档

讨论稿 · 2026 年 11 月 25 日

桌面上的红点是 Orbit 的眼睛。平时它安静地待在原处，偶尔朝鼠标方向看一眼。需要提醒时，它在身边说一句短话。用户长时间坐在电脑前时，先靠本机给出少量关怀提醒。将来如能获得受支持的消息来源，同一个小球也可以显示 ChatGPT 的 dot 发来的更新。

## 1. 红点看向鼠标

- 小球外壳和点击范围固定，只有内圈的红点轻微偏移。鼠标靠近，小球平滑地看过去。鼠标移远或停留一段时间后，红点缓慢回到中心。
- 视线动效和鼠标进入工具托盘各自处理。移动视线时，小球和托盘的位置保持稳定。正在拖放或倒计时，先保证接收提示和剩余时间清楚可读。
- 视线只用当前鼠标位置，在本机即时计算。设置里可关闭视线动效。

## 2. 本机的轻提醒

首版用小球旁的一行文字气泡。气泡自动淡出，保留键盘焦点，用户可以直接忽略。提示语像一句关心，尽量少打断。若后续加入语音，建议由用户单独开启。

| 建议的默认触发 | 气泡示例 | 频率 |
| --- | --- | --- |
| 持续工作约 1 小时 | 喝口水吧。 | 同一段工作先提示一次。 |
| 持续工作约 3 小时 | 做了挺久了，起来走两步？ | 达到时提醒一次，下一段工作再计。 |
| 本机时间凌晨 3–4 点，且近期仍在活动 | 已经很晚了。差不多的话，今天先到这儿吧。 | 每晚最多一次。 |

- 以 Orbit 正在计时的工作和系统近期是否空闲作为触发线索。可单独验证未开启计时器时的长时间电脑使用提醒，文案用「在电脑前挺久了」，避免把所有键鼠活动都当作工作。
- 长时间离开、锁屏或休眠后，从返回时重新计算连续使用时长。错过的普通提醒直接跳过。同一时间撞上几条时，只保留最合适的一条，例如休息和活动合成一句。刚响过任务完成铃、拖放进行中或全屏时，关怀气泡等到合适的时候再显示。
- 提醒可在小球菜单里静音。类型和间隔先用默认值，等实际体验后再决定要开放哪些设置。只需在本机判断当前时段和是否空闲，提醒运行不依赖 ChatGPT 账号或网络。

## 3. 在小球上显示 dot 消息

目标是让小球成为 dot 更新在 Windows 上的查看入口。气泡标明来源，平时只显示简短摘要；需要处理时，点击打开原消息。优先验证「定时提醒」和「任务需要你确认」两个例子，测清哪些有支持的接收渠道，以及账号退出后能收到哪些。

- **只收起 ChatGPT 窗口。** 如果 dot 已经通过受支持的渠道把消息送到 Windows，可以验证 Orbit 能否在用户授权后转显这类通知。Windows 有通知监听能力，具体能否用在 Orbit 当前的桌面打包方式、能收到哪些 ChatGPT 通知，都要用真实投递验证。读取时只处理用户选定的来源。 [Windows 通知监听说明](https://learn.microsoft.com/en-us/windows/apps/develop/notifications/app-notifications/notification-listener)
- **ChatGPT 桌面应用完全退出或已登出。** dot 通过 ChatGPT 使用本机的能力要求桌面应用正在运行且已登录。要在退出后继续把云端消息送到 Orbit，需有另一个仍获授权的渠道。可先验证用户指定的 Slack 目的地，或者该账号支持的定时任务邮件。Slack 不会自动镜像 ChatGPT 里的所有消息。面向个人的公开文档目前也未确认全量转发接口，因此「所有推送」先保留为目标。 [dot 的本机访问条件](https://learn.chatgpt.com/docs/enterprise/cloud-local-access#end-user-experience) · [dot 的消息渠道](https://learn.chatgpt.com/docs/dots/channels) · [定时任务的通知设置](https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt)

首次接入时，选择要接收的来源和事件，再用一条测试消息验证。收到同一条消息时只弹一次，点开原消息处理具体事项。日记共享与消息接收各自授权。 [自动日记任务文档](automatic-journal.md)

## 4. 交付顺序与验收

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| 第一阶段 | 红点视线动效 | 远近移动鼠标时眼睛跟随自然。小球本体、拖放命中、工具栏和倒计时位置稳定。 |
| 第二阶段 | 本机提醒气泡 | 1 小时与 3 小时触发各一次，凌晨持续活动只提醒一次。锁屏或休眠回来没有补弹，关怀气泡不抢焦点。断网、未登录 ChatGPT 时仍运行。 |
| 第三阶段 | dot 消息接收验证 | 分别测试收起窗口、退出桌面应用、登出账号时选定渠道的实际投递。能送达的消息在小球旁出现一次并带来源；把验证过的事件类型和条件写进设置说明。 |
