# Singularity · Orbit v0.5.0

奇点项目的 Windows 桌面助手：一个悬浮小点，打开任务计时器、记事本和自动记录最近 3 项的剪贴板。

设计以清晰、可读、极简为先，采用深石墨色、少量紫色操作提示和冷青色计时状态。图标由原生矢量绘制，界面通过轻微凸起和内凹层次体现新拟态；悬停和点击动效结束后回到原始尺寸，保持文字清晰。

这是根据计划书和本次需求重新实现的原生 Windows MVP，并非从 Base44 导出的源码。界面使用 WPF，适用于安装了 .NET Framework 4.8 的 Windows 10 / 11；运行不依赖 Chrome，不需要账号，也不连接网络。

## 开始使用

1. 双击 `Orbit.exe`（源码工程中位于 `dist\Orbit\Orbit.exe`），屏幕右侧会出现悬浮小点。
2. 单击小点，只展开三个工具按钮：**任务计时器、记事本、剪贴板**。点击其中一个，打开对应面板。
3. 点击任务计时器后，光标自动进入名称输入框。输入名称，按 **Enter** 转到时长；输入分钟数，再按 **Enter**，任务加入列表，此时尚未计时。
4. 点击任务行右侧的 **▶** 才开始倒计时。小点只显示剩余时间，任务名称保留在清单中。
5. 时间到时播放提示音，之后每 4 秒重复一次。单击小点，或点击 **知道了 · 停止提醒**，即可确认并停止声音。

第一次可以输入「试一下」，按 Enter，输入 `10s`，再按 Enter，最后点该任务右侧的 ▶，体验完整流程。

## 时长与任务清单

填写时长时，默认按分钟计算，支持 1 秒至 24 小时；也可以留空，创建仅需勾选完成的清单任务。

| 输入 | 时长 |
| --- | --- |
| `25` 或 `25m` | 25 分钟 |
| `10s` | 10 秒 |
| `1h30m` 或 `1小时30分钟` | 1 小时 30 分钟 |
| `1:30` | 1 分 30 秒，格式为 `分钟:秒` |
| `1:30:00` | 1 小时 30 分钟，格式为 `小时:分钟:秒` |

- **名称留空**：自动使用「日期 · 任务编号」命名，同一天的编号递增。
- **时长留空**：创建普通清单任务，通过勾选标记完成，不启动倒计时，也不响铃。
- **计时任务**：右侧 ▶ 开始或继续，Ⅱ 暂停。同一时刻只运行一个任务；启动另一项时，原任务暂停并保留剩余时间。
- **调整顺序**：拖动未完成任务的行或拖动手柄重新排序，任务原来的名称和时长保持不变。
- **固定面板**：任务增加不会拉长面板，超出内容在内部滚动；滚动条是一根使用文字色、80% 透明度的细圆角竖线，仅在需要时显示，支持滚轮与拖动。
- **右键任务**：可以删除任务；当前计时任务还可以提前完成。计时任务提前完成会进入完成提醒，普通清单任务勾选完成不响铃。

已有完成提醒时，先确认提醒，再开始下一项计时任务。

## 记事本与剪贴板

**记事本**支持多行文字，停止输入约 500 毫秒后自动保存到本机。底部显示保存状态；如果保存失败，草稿保留在面板中，程序会阻止可能丢失草稿的切换或退出。

**剪贴板**在 Orbit 运行期间自动收集复制的文字和图片，面板收起时也继续工作：

- 固定 **3 个槽位**，最新内容在第一位，原有记录依次后移；第 4 条自动移出历史。
- **文字**显示内容预览，取用时复制完整文字。
- **图片**显示缩略图、文件名和尺寸；支持截图、复制图片，以及在资源管理器中复制图片文件。没有原始文件名时使用时间生成名称。
- 点击记录或其 **复制** 按钮，将内容放回系统剪贴板，再到目标应用按 **Ctrl+V**。取用旧记录会移到首位，不生成重复副本。
- **拖出使用**：按住卡片上的文字或图片，拖到文件夹或支持拖放的网站。图片导出为 PNG，保留原文件名主体；文字同时提供纯文本和 UTF-8 `.txt` 文件，文件夹会收到文本文件，网站按自身的拖放规则接收文字或文件。
- 单击仍然复制；移动超过拖动距离才开始拖出，按 **Esc** 可取消。拖动不会改写系统剪贴板、删除记录或调整历史顺序。
- 删除按钮只移除该条历史，不改变系统剪贴板，也不删除原始图片文件。

记录和图片副本仅保存在本机，重启后恢复最近 3 项。剪贴板被其他应用短暂占用时会自动重试。第一版不收存普通文件、文件夹或富文本格式；复制的文字按纯文本保存。

一次复制多个图片文件时，记录其中首张可读取的图片；动图记录第一帧。图片副本使用 PNG，单张最大 32 MiB、约 2500 万像素，单边不超过 16384 像素；文字最多 100 万字符。超出限制或格式无法读取时会在面板提示。

## 小点与托盘

- 按住小点拖动可调整位置；拖动结束不会打开面板。
- 工具条展开时，再次单击小点会收起工具条及全部面板。正在响铃时，单击小点优先确认提醒。
- 点击面板的 **×** 或在面板内按 `Esc`，只关闭当前面板，保留三个工具按钮。收起界面不影响倒计时。
- 三个工具按钮的位置只跟随小点与屏幕边界。展开、切换或增加任务不会带动工具条；下方空间不足时只调整子面板的位置，靠近边缘时优先利用可读的下方空间并缩短内部滚动区域。
- 右键小点可以暂停、继续、重新计时、静音、将小点放回屏幕右侧，或退出程序。可用操作会随当前任务状态变化。
- 静音只关闭声音，屏幕提醒仍会显示；静音设置仅在本次运行期间生效。
- 系统托盘也提供打开任务清单、恢复小点位置、停止提醒及退出入口。
- 退出程序请使用 **退出 Orbit**。

## 本地保存

数据保存在本机目录：

```text
%LOCALAPPDATA%\Singularity\Orbit\
```

| 文件 | 内容 |
| --- | --- |
| `state.json` | 任务、顺序、完成记录、小点位置和每日任务编号 |
| `notes.txt` | 记事本文字 |
| `clipboard-history.json` | 最近 3 项剪贴板记录及图片信息 |
| `clipboard-history-images/` | 历史图片的 PNG 副本，移出历史后清理副本 |
| `clipboard-drag-exports/` | 拖出的独立文件副本，留给目标应用读取；超过 7 天未使用时清理 |

新版本兼容旧版 `state.json`，不需要手动迁移。旧版 `clipboard-slots.json` 中的文字会迁入自动历史，原文件保留。记事本和剪贴板使用独立文件。

运行中的任务按实际截止时间计算。退出后，原定截止时间仍然有效；下次打开时会恢复倒计时，已经到期的任务会进入完成提醒。暂停的任务不会扣除离线期间的时间。

**程序未运行、电脑关机或休眠期间无法响铃。** 重新启动程序或电脑从休眠恢复后，会检查到期状态并提醒。若希望离开程序期间不计时，请先暂停任务。

读到损坏的任务数据时，程序会尝试保留一份 `.corrupt.json` 备份；若原文件无法安全读取或备份，会暂停保存，避免覆盖原数据。记事本和剪贴板文件读取失败时会保留原文件并显示提示。

## 从源码构建

构建需要 Windows、.NET Framework 4.8 引用程序集和 C# 编译器。无需 NuGet 包。开发环境可使用包含这些组件的 Visual Studio 或 .NET Framework 4.8 Developer Pack。

在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

构建产物位于 `dist\Orbit\Orbit.exe`。复制使用时，请保留同目录中的配置文件。

主要文件：

- `src/TimerEngine.cs`：任务状态、时长解析和倒计时逻辑。
- `src/DesktopApp.cs`：桌面小点、窗口定位和托盘交互。
- `src/PopupLayout.cs`：独立工具条锚点、子面板方向与屏幕边界计算。
- `src/LauncherWindow.cs`：三个工具按钮与共享动效。
- `src/TaskPanel.cs`、`src/Panel.xaml`：任务面板、键盘输入和拖动排序。
- `src/UtilityPanels.cs`：记事本和三槽剪贴板预览。
- `src/ClipboardHistory.cs`：三条历史、图片缓存和本地保存。
- `src/ClipboardMonitor.cs`：Windows 剪贴板事件监听、文字图片读取与复制。
- `src/ClipboardDragExport.cs`：供文件夹和网站接收的拖放文件与数据格式。
- `src/PlatformServices.cs`：本地存储、提示音与 Windows 窗口辅助。
- `tests/TimerEngineTests.cs`：计时核心测试。
- `tests/PopupLayoutTests.cs`：位置稳定、边界、方向切换与负坐标显示器测试。
- `tests/ClipboardHistoryTests.cs`、`tests/ClipboardMonitorTests.cs`：历史淘汰、图片格式、保存恢复和自动监听逻辑；使用隔离数据，不改动日常剪贴板。
- `tests/ClipboardDragExportTests.cs`、`tests/ClipboardDragInteropTests.cs`：拖出文件、名称、导出缓存和 Windows 原生拖放格式检查。
- `tests/clipboard-browser-drag-test.mjs`：独立 Chrome 页面接收检查，使用临时配置目录和本地文件，验证文本框与文件上传控件；不会上传数据，不等同于真实鼠标跨应用拖放。
- `tests/ClipboardNativeTests.cs`：单独进程中的 Windows 剪贴板回环检查，需允许创建私有 window station；无法建立隔离环境时跳过，不访问日常剪贴板。
- `tests/UiSmokeTests.cs`：桌面操作与界面截图检查。运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1 -SmokeTest` 可复查；自动测试期间静音，数据与日常任务隔离。

## 源码同步

源码仓库为 [TsuIppaku/Singularity](https://github.com/TsuIppaku/Singularity)，分支为 `main`，当前 Orbit 应用位于仓库根目录。

完成一次开发更新并通过相关检查后，Codex 按 `AGENTS.md` 中的约定提交并上传源码 tree。可以运行 `powershell -ExecutionPolicy Bypass -File .\scripts\prepare-github-tree.ps1` 生成上传清单 `artifacts/github-tree.json`；生成清单本身不会上传代码。

清单只包含源码、测试、构建脚本和项目文档。任务记录、记事本、剪贴板内容、图片缓存、凭据、测试产物和安装包均不进入源码同步。

## 当前范围

这一版包含任务清单与计时提醒、本地记事本、自动收集文字和图片的三槽剪贴板，以及紧凑工具条和基础交互动效。日历预约、开机自启、工作监督、普通文件收存、跨设备互传及完整桌宠动画尚未实现。
